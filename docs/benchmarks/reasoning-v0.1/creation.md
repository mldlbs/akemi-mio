# Creation Benchmark — v0.1

Questions requiring writing, design, content generation, creative output.
No Level 3 Pattern标注.

---

**C01**
User > "帮我想一个项目名字"
Expectation > [发散思路, 给出建议, 说明理由]

**C02**
User > "写一段关于这个功能的介绍文档"
Expectation > [组织内容, 说明功能, 规划文档结构]

**C03**
User > "这个 API 的 README 应该怎么写？"
Expectation > [规划结构, 列出要点, 给出模板]

**C04**
User > "给我的项目写一个贡献指南"
Expectation > [规划结构, 列出要点, 给出参考]

**C05**
User > "帮我设计这个页面的布局"
Expectation > [设计方案, 说明理由, 描述交互流程]

**C06**
User > "这个错误信息应该改成什么？"
Expectation > [评估现状, 给出改进方案, 说明原因]

**C07**
User > "画一个架构图来描述这个系统"
Expectation > [规划结构, 列出组件, 描述关系, 说明分层]

**C08**
User > "帮我写一封技术方案评审邮件"
Expectation > [组织内容, 规划结构, 列出要点]

**C09**
User > "给这个模块写一个测试计划"
Expectation > [规划测试范围, 列出测试用例, 说明测试策略]

**C10**
User > "这个用户反馈应该怎么回复？"
Expectation > [分析反馈, 组织回应, 给出回复建议]

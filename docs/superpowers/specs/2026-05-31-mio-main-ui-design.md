- 极简毛玻璃（Glassmorphism）

## 4. 核心元素

### 4.1 3D 环形波形动画

**结构**
- 渲染引擎：Three.js WebGL
- 配置：`alpha: true`, `antialias: true`, `pixelRatio` 上限 2
- 柱子数量：128 根
- 排列：圆形均匀分布，底部立于圆周上，朝外径向排列

**柱子规格**
- 单体几何：`BoxGeometry(0.04, 0.1, 0.04)`
- 基准半径：`2.2`（圆心到柱底距离）
- 高度缩放：`scale.y` 范围 `0.3 ~ 6.0`
- Y 轴定位：`position.y = scale.y * 0.5 - 0.5`（底部固定，向上生长）
- 混合模式：`AdditiveBlending`，`depthWrite: false`
- 透明度动态范围：`0.2 ~ 0.8`，随高度增加

**配色渐变（四段循环）**
- `0°~90°`：`#E7E2A8` → `#E68906`
- `90°~180°`：`#E68906` → `#D25529`
- `180°~270°`：`#D25529` → `#CF8B5A`
- `270°~360°`：`#CF8B5A` → `#E7E2A8`

**中心光点**
- 几何：`SphereGeometry(0.12, 32, 32)`
- 材质颜色：`#E68906`
- 呼吸动画：`scale = 1 + sin(t*3) * 0.5`，活跃态振幅加倍
- 透明度脉动：`0.5 + sin(t*2) * 0.3`

**动画逻辑**（`requestAnimationFrame` 驱动）

| 状态 | 柱高波形公式 | 旋转速度 |
|------|-------------|---------|
| 空闲 | `0.8 + sin(p*5 + t*0.6)*0.4` | Y: `0.001` + Z: `0.0005` rad/frame |
| 监听中 | 介于空闲与活跃之间，低频微动 | Y: `0.002` rad/frame |
| 说话中/识别中 | `1.5 + abs(sin(p*8+t*2))*2.5 + sin(p*20+t*5)*1.0 + sin(p*3+t*1.5)*1.5` | Y: `0.004` + Z: `0.002` rad/frame |
| TTS 回复 | 振幅约为活跃态的 60% 的温和脉动 | Y: `0.002` rad/frame |

- `p = i / 128`（归一化位置），`t = performance.now() * 0.001`
- 每帧按 `0.1` 因子向目标值 lerp，自然过渡
- 空闲超过 10s 降至 30fps

**清理**
- 组件卸载时：取消 `requestAnimationFrame`，释放 geometry/material，移除 DOM

### 4.2 跑马灯字幕条

**位置**
- 波形正下方，间距 12px

**容器**
- `background: rgba(231, 226, 168, 0.10)`
- `backdrop-filter: blur(16px)`
- `border: 1px solid rgba(207, 139, 90, 0.15)`
- 宽度 100%，高度 48px
- `border-radius: 12px`
- 水平居中

**文字**
- 颜色：`#E7E2A8`
- 字号：15px，行高 48px，`letter-spacing: 0.4px`
- 文本阴影：`0 2px 12px rgba(128, 56, 16, 0.5)`
- 跑马灯动画：从右向左匀速 `translateX` 滚动，速度 ~50px/s
- 文本前后留白 20px（`padding`）

**状态**
- 无内容时整条隐藏（`display: none` / `opacity: 0`）
- 入场动画：从下方上浮 8px + 淡入，0.5s ease-out
- 3 秒无新内容后整体淡出

### 4.3 麦克风按钮

**位置**
- 字幕条正下方，间距 12px

**规格**
- 56×56px，圆形，`border-radius: 50%`
- `background: rgba(255,255,255,0.08)`，`backdrop-filter: blur(8px)`
- `border: none`，`cursor: pointer`
- 无文字图标（🎤 或自定义 SVG）

**状态**

| 状态 | 表现 |
|------|------|
| 闲置 | 白色半透明，图标 `opacity: 0.55` |
| 活跃（监听/识别中） | 琥珀金 `#E68906`，`box-shadow: 0 0 32px rgba(230,137,6,0.3)`，脉动周期 2s |
| 说话中 | 赤陶橙 `#D25529`，同上脉动 |
| TTS 回复中 | 琥珀金脉冲 |

**过渡**：所有状态切换 `0.35s ease-out`

### 4.4 状态文字

**位置**
- 麦克风按钮正下方，间距 6px
- 字号 10px，颜色 `rgba(231, 226, 168, 0.5)`

**内容**
- 监听中 → `监听中...`
- 说话中 → `说话中...`
- 识别中 → `识别中...`
- TTS 回复 → `回复中 ♪`
- 空闲/错误 → 对应错误信息或隐藏

## 5. 交互状态表

| 状态 | 波形 | 字幕条 | 麦克风 | 状态文字 |
|------|------|--------|--------|----------|
| 空闲 | 慢速旋转 | 隐藏 | 白色半透明 | 隐藏 |
| 监听中 | 微动 | 隐藏 | 琥珀金呼吸光 | `监听中...` |
| 说话中 | 活跃跳动 | 隐藏 | 赤陶橙呼吸光 | `说话中...` |
| 识别中 | 活跃跳动 | 隐藏 | 琥珀金常亮 | `识别中...` |
| TTS 回复 | 温和脉动 | 跑马灯滚动 | 琥珀金脉冲 | `回复中 ♪` |

## 6. 动效规范

| 动效 | 参数 |
|------|------|
| 状态切换过渡 | `0.35s ease-out` |
| 字幕条入场 | 上浮 8px + 淡入，`0.5s ease-out` |
| 字幕跑马灯 | ~50px/s 匀速 `translateX` |
| 麦克光环脉动 | 2s 周期 |
| 波形空闲降帧 | 连续无操作 10s 后降至 30fps |
| 自动淡出 | 连续无操作 10s 后整体淡出 |

## 7. 约束

- 透明背景，不可点击区域穿透鼠标事件给桌面
- 最小窗口 400×300px，内容不溢出
- 文字阴影确保浅色壁纸可读性
- WebGL `pixelRatio` 上限 2，性能优先
